F — IMPOSSIBILIDADE DE ISOLAMENTO
No commit fixado, ggml/src/CMakeLists.txt contém a rejeição fatal:
if (GGML_CPU_ALL_VARIANTS) ... elseif (GGML_CPU_ARM_ARCH)
message(FATAL_ERROR "Cannot use both GGML_CPU_ARM_ARCH and GGML_CPU_ALL_VARIANTS")
Portanto F não pode compilar mudando SOMENTE ARM_ARCH em relação a A. Desligar ALL_VARIANTS junto seria uma segunda variável independente, proibida aqui. Essa dependência foi informada antes da implementação.
F recebe ISOLATION_INVALID / CONFIGURATION_REJECTED, log real da configuração, controles solicitados, metadata e cache parcial quando disponível. Não há APK fictício nem uma variante F de duas variáveis apresentada como isolada. Esta é a exceção expressamente permitida pelo critério de impossibilidade de F.
E NÃO força ARM_ARCH. Com ALL_VARIANTS OFF, o build usa o alvo padrão ARM64 do NDK; flags ISA efetivas são registradas nos comandos do compilador. O alvo que resultar disso é consequência de uma opção, não uma segunda flag imposta silenciosamente.

USO FUTURO — SEM INFERÊNCIA NO CI
Instalação é manual e somente no sandbox. As variantes atuais da matriz são compatíveis entre si via install -r (certificados verificados no build). Não usar pm clear/uninstall, nem comandos direcionados ao app normal.
Após extrair o artifact, informar SHA/tamanho conhecidos, ou referência4.5:
python scripts/diagnostic46_run.py --serial SERIAL --variant A_CURRENT --bundle . --reference45 CAMINHO/A1_45 --out evidence46/A_CURRENT --probes 3,4
OU usar --expected-sha256 SHA_CONHECIDO --expected-bytes TAMANHO_EXATO em vez de --reference45.
Antes de cada modo, instalar manualmente o app-debug.apk e o androidTest da pasta correspondente. O script mede o APK instalado; se a instalação falhou/deixou outro modo, a execução é recusada. Não há modelo enviado/recebido automaticamente.
Repetir com C_NO_KLEIDIAI, D_NO_REPACK, E_NO_ALL_VARIANTS e B_CONSERVATIVE usando o MESMO arquivo já validado, sem alterar parâmetros. F não é uma escolha executável.
Comparação principal:
python scripts/diagnostic46_matrix.py --evidence-root evidence46 --output matrix-device46.json --reference45-a CAMINHO/A1_45 --reference45-b CAMINHO/B1_45
