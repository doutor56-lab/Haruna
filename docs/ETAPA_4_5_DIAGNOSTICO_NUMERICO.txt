LOGS / NUMÉRICA
Até512 registros tokens.jsonl: índice1-based, ID, posição, seq0, KV, piece UTF-8 quando válido, pieceHex exato (fragmentos multibyte permitidos), EOG, logit bruto escolhido, probabilidade pós-sampler disponível, finitos/NaN/Inf e extremos. tokens.txt apresenta TOKEN 0001 | id=... | texto | posição | logit | p. Não registra vocabulário/logits completos por token, não reamostra nem aplica sampler novamente.
Duas passagens: (1) geração livre A/B para obter FIRST_DIVERGENCE por IDs; (2) replay explícito com no máximo DOIS vetores finais de logits float32 little-endian, normalmente k-1 e k. Aproximadamente600KiB por vetor para vocabulário de~150mil; não há dump gigante de tensores/camadas. Arquivos só no sandbox diagnóstico/exportação explícita.
Compara max_abs_diff, mean_abs_diff, RMS nos pares finitos, NaN/Inf por token e pares não finitos. Não diz que vetores com NaN são iguais nem inclui Inf em médias. Verifica condicionamento por IDs [1,k-1] iguais ANTES do token k. Depois de históricos divergirem, rejeita a comparação numérica. Com referências da primeira passagem, rejeita replay que não reproduza o prefixo original até a sonda.
A primeira divergência de IDs NÃO é necessariamente a primeira diferença em float: podem existir diferenças desde o primeiro prefill sem mudar o token selecionado. Para localizar progressivamente, capturar passo1 e outros pontos dentro do prefixo comum. Magnitude numérica ou divergência de IDs isoladas não provam degeneração.
Não captura saída da última camada nem tensores intermediários nesta implementação: isso exigiria instrumentação adicional do grafo. Primeiro avalia os logits finais conforme prioridade solicitada.

ROTEIRO (PC COM PYTHON3 + ADB, USB DEBUGGING AUTORIZADO)
1. Extraia o pacote de diagnóstico no computador. Feche/force a parada da Haruna normal, mantendo dados. Não use adb uninstall/pm clear na Haruna.
2. Instale A e seu APK de instrumentação (nomes no artefato):
   adb -s SERIAL install -r A_CURRENT/app-debug.apk
   adb -s SERIAL install -r A_CURRENT/app-debug-androidTest.apk
3. Descubra o caminho relativo do GGUF já instalado:
   adb -s SERIAL shell run-as com.proxyslabs.haruna find files -name '*.gguf'
   Se run-as for recusado (Haruna não-debuggable), não remova o app; use uma cópia original do mesmo GGUF no computador para transferir apenas ao sandbox de teste, ou solicite orientação.
4. Copie uma vez:
   python scripts/diagnostic45_copy_model.py --serial SERIAL --source-model files/CAMINHO/DO/MODELO.gguf
5. Execute A; não abra a Haruna durante os testes:
   python scripts/diagnostic45_run.py --serial SERIAL --model diagnostic45.gguf --out evidence/A1
   Repita em evidence/A2 para verificar estabilidade do próprio A (cada invocação força parada apenas do aplicativo diagnóstico, sem apagar dados).
6. Instale B por cima do MESMO aplicativo diagnóstico, preservando sua cópia do GGUF. A/B são assinados no mesmo job. Instale B e seu instrumentation APK, sem desinstalar:
   adb -s SERIAL install -r B_CONSERVATIVE/app-debug.apk
   adb -s SERIAL install -r B_CONSERVATIVE/app-debug-androidTest.apk
   python scripts/diagnostic45_run.py --serial SERIAL --model diagnostic45.gguf --out evidence/B1
7. Compare:
   python scripts/diagnostic45_compare.py evidence/A1 evidence/B1 --output evidence/compare-free.json
8. Se FIRST_DIVERGENCE=k, reinstale A, execute --probes k-1,k em diretório A-probe novo; reinstale B e repita em B-probe. Para k1 use apenas1. Máximo dois índices. Use os índices concretos indicados pelo comparador, não a string literal k.
   python scripts/diagnostic45_compare.py evidence/A-probe evidence/B-probe --reference-a evidence/A1 --reference-b evidence/B1 --output evidence/compare-numeric.json
9. Envie arquivos de texto/JSON e resultado da comparação; os vetores são pequenos e podem ser enviados se necessário. Conteúdo é somente a pergunta canônica. Não enviar arquivos normais de chats/memórias.
10. Após exportar, o aplicativo diagnóstico pode ser removido pelo usuário para recuperar o espaço da cópia GGUF. Isso não remove Haruna nem seus dados. Remoção é manual, não executada por scripts.
