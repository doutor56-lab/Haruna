LEGENDA DOS NOVOS CAMPOS
stage: última etapa; failedStage: primeira etapa com falha. idle = nenhuma falha registrada.
decodeReturn: null = chamada não retornou/não iniciou; 0 = sucesso; valores originais do llama_process (API encaminha decode).
Na API decode desta revisão: 1 = sem slot KV; 2 = abort; -1 = batch inválido; -2 = falha de alocação; -3 = falha de computação. É necessário correlacionar com cancelamento e logcat: um código sozinho não identifica o driver culpado.
exceptionKind: 0 = nenhuma exceção capturada; 1 = bad_alloc; 2 = system_error; 3 = std::exception; 4 = exceção desconhecida.
systemCode: código numérico original, somente quando exceptionKind=2; null nos demais casos.
systemCategory: 0 = ausente; 1 = vk::Result; 2 = system; 3 = generic; 4 = outra. Não interpretar um código generic como VkResult.
technicalHint: 0 = nenhuma classificação; 1 = mensagem upstream exata de shared memory insuficiente para matmul; 2 = unsupported FaCodePath; 3 = Unsupported device. Não contém mensagem original.
